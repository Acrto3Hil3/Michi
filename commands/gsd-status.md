description: Print the current phase, its status, and what's next
---

Read `docs/PROGRESS.md` and the `docs/phases/` directory. Don't read source code.

Report, briefly:

- **Current phase** and its Status line (`discussing` / `planned` / `executing` /
  `verifying` / `done`)
- **Where it stands** — which plan steps are checked, which is next
- **Anything blocking** — open questions from the Discussion section that are still
  unanswered
- **What's verified vs. merely built** — call this out honestly; they're different
- **Known follow-ups** currently tracked, and whether any revisit trigger has been hit
- **Suggested next command** — `/gsd-discuss`, `/gsd-plan`, `/gsd-execute`, or
  `/gsd-verify`

Keep it to a short summary someone can read in ten seconds. If `docs/PROGRESS.md`
doesn't exist yet, say so and suggest `/gsd-init`.
